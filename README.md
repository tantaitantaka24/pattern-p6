# เฉลยแบบรูป ป.6 เล่ม 1 · บทที่ 5

เฉลยแบบละเอียด เห็นภาพ กดไล่ทีละขั้น ของแบบฝึกหัด 5.3–5.4 (หน้า 134–147)
รายวิชาพื้นฐานคณิตศาสตร์ ชั้นประถมศึกษาปีที่ 6 เล่ม 1 (สสวท.)

- 26 ข้อ แต่ละข้อมี 4–6 ขั้น: ดูโจทย์ → นับ → แยกส่วนด้วยสี → เขียนความสัมพันธ์ → ตรวจสอบ → หาคำตอบ
- แท็บ **ลองรูปที่ n** เลื่อนดูรูปที่เท่าไรก็ได้ พร้อมจำนวนที่คำนวณให้
- ข้อลูกบาศก์ ขนมลูกเต๋า และขนมน้ำดอกไม้ แสดงเป็นภาพ 3 มิติ หมุนได้ (Three.js ต้องต่ออินเทอร์เน็ต)
- ใช้ลูกศร ← → บนคีย์บอร์ดเพื่อไปขั้นถัดไป ใช้ได้ทั้งคอมพิวเตอร์ โปรเจกเตอร์ และมือถือ

ไฟล์เดียว `index.html` เปิดในเบราว์เซอร์ได้เลย

รูปทุกรูปวาดใหม่ด้วยโค้ด วิธีคิดอ้างอิงตามคู่มือครูของ สสวท.
